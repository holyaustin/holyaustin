## 🚀 What I'm Working On

### 🎟️ CACK-pass — Web3 Event Ticketing & Payments

I'm building **CACK-pass**, a Web3-enabled event ticketing and management platform designed to make live-event access more transparent and verifiable.

The project explores:

- 🎫 NFT-based event tickets
- ⛓️ Blockchain-verified payment records
- 💳 Fiat and crypto payment integration
- 💰 USDC payments on Arc
- 👛 Wallet-based payments with Privy
- 🧾 Event, ticket and order management
- 🔐 Verifiable ticket ownership
- 📊 Payment reconciliation and auditability
- 🏦 Organizer payment and payout workflows
- 🌍 Accessible event ticketing for emerging markets

The goal is simple:

> **Make event access more trustworthy, transparent, and rewarding for organizers and attendees.**
